How scores work

Scores on this starter website are entered manually by an organiser/scorer using the Admin Panel. Demo matches are clearly marked. This website does not automatically fetch official score feeds.

Important: this free starter stores changes in this browser only. To let all visitors see the same live scores, connect a shared database and secure admin login before publishing it publicly.
